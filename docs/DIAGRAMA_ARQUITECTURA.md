4. Alternativa: guarda el JSON en un archivo `diagrama.excalidraw` y usa `File → Open` dentro de Excalidraw.

## Leyenda de colores

- 🟩 Verde: activo / en producción hoy.
- 🟥 Rojo: deshabilitado.
- 🟨 Amarillo: plantilla, pendiente de implementar, o sin datos reales todavía.
- 🟦 Azul: coordinador/servicio de orquestación.
- ⬜ Gris: solo-consulta (no participa del `DomainEventBus`).

## Flujo representado

```
API TipMiner (Bac Bo) → GameEventCollector → HistoryStore (200 jugadas en memoria)
                                           → DomainEventBus.publish(GameReceivedEvent)
                                                ├── StrategyCoordinator (ignora históricas)
                                                │     ├── Streak3Strategy      [DESHABILITADA]
                                                │     ├── Streak4Strategy      [ACTIVA] ──► OperationCoordinator
                                                │     │                                      └── Operation: OPEN→MG1→MG2→WON|LOST (TIE reinicia)
                                                │     │                                            └── NotificationCoordinator
                                                │     │                                                  ├── TelegramChannel Oficial  (grupo "oficial")
                                                │     │                                                  └── TelegramChannel Pruebas  (grupo "pruebas")
                                                │     └── Alternancia34Strategy [PLANTILLA/DESHABILITADA]
                                                ├── StatisticsService + EngineMetricsService (cuentan TODO, incl. histórico)
                                                └── (futuro, punteado) PersistenceModule/PrismaService → tabla `jugadas` en Supabase

ReportScheduler (horario) + AdminController (POST /admin/commands RESUMEN) → SummaryReportService → ambos canales de Telegram
EngineHealth (solo-consulta, GET /healthz) lee HistoryStore/Collector/OperationCoordinator/estrategias/canales — no participa del bus.
```
